# Mission Kerala 2027

A personal, mobile-friendly countdown and preparation tracker for the two-year TCS milestone on **28 August 2027**.

## Features
- Live countdown to the milestone
- Weekday counter (Monday–Friday; excludes weekends, not public holidays)
- Elapsed service progress from 28 August 2025
- Milestone timeline
- Transfer-preparation checklist
- Private notes saved in the current browser

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Vercel framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Privacy
Checklist progress and notes are stored in browser localStorage on the device/browser being used. No backend or account sync is configured.

## Important
The two-year date is a personal target, not a confirmation of TCS transfer eligibility or approval. Verify the current internal mobility policy with HR.
